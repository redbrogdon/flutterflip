# flutterflip_shared

A pure Dart package containing the core board state representation, score evaluation heuristics, and game models for flutterflip.

## Features

- **GameBoard**: Immutable Reversi/Othello board representation.
- **GameModel**: Manages game state (active player, current score, legality checks, game-over detection).
- **GameBoardScorer**: Heuristic scoring engine.
